# Frankie 2.0 Life OS - Permanent PWA

This is the permanent app-ready version of Frankie 2.0.

## What it includes

- iPhone-style Progressive Web App structure
- Home Screen icon
- Offline support after first load
- Saved inputs using local storage
- FIRE / asset projection calculator
- Usable equity calculator
- Rental cashflow estimate
- Daily mission tracker
- Life score
- Mentor prompt engine
- Backup and restore tools

## Permanent hosting option - GitHub Pages

1. Create a free GitHub account.
2. Create a new repository called `frankie-2-life-os`.
3. Upload every file in this folder.
4. Go to repository Settings.
5. Open Pages.
6. Under Build and deployment, choose Deploy from branch.
7. Select branch `main` and folder `/root`.
8. Save.
9. GitHub will give you a permanent website link.
10. Open that link in Safari on your iPhone.
11. Tap Share.
12. Tap Add to Home Screen.
13. Name it Frankie 2.0.

## Updating the app later

When you want changes, ask ChatGPT to update the app files. Then replace the files in the GitHub repository. Your permanent link stays the same.

## Backup

Use the Setup tab inside the app to export a JSON backup of your saved numbers and settings.
