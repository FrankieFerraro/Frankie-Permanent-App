Permanent App Setup

No timer
  1. Create a free GitHub account.
  2. Create a new repository called frankie-2-life-os.
  3. Upload all files from this folder.
  4. Go to Settings → Pages.
  5. Select Branch → main → root.
  6. Open the GitHub Pages link in Safari.
  7. Tap Share → Add to Home Screen.

Once hosted, this works like a permanent iPhone app. No Netlify Drop timer.
